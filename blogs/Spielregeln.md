# Spielregeln

Das ist ein Platzhalter Text. Hoffentlich werden die Karten bald veröffentlicht!
 
## Spielablauf
Ausgangssituation
Zwei Stufen (Die beiden Spieler) wollen am MWG Geld sammeln für den tollen Abiballplatz, doch nur eine Stufe kann sich den Platz reservieren. Wer sammelt zuerst genug Geld, um sich den Platz zu sichern?
Ziel des Spiels
Wer zuerst 10000 (?) Euro sammelt, gewinnt.
### Aufbau
Jeder Spieler hat ein Deck an Karten. Das Deck besteht aus Lehrern (<= 6-7), Itemkarten, Sabotagekarten, Eventkarten und Klassenraumkarten. Zunächst zieht jeder Spieler x Karten.  
Zug
Zunächst zieht der Spieler eine Karte.
Innerhalb eines Zuges, kann ein Spieler folgende Aktionen durchführen:
-	Einen neuen Lehrer anwerben (Maximal einmal pro Zug)
-	Spezialfähigkeit eines Lehrers (Pro Lehrer/Spiel maximal einmal)
-	Klassenraumkarten ausspielen (Maximal einmal pro Zug)
-	Items verwenden
-	Sabotagen ausspielen
Der Zug wird beendet, indem entweder der Spieler eine Eventkarte ausspielt oder dies aussetzt. In dem ersten Zug darf keine Eventkarte ausgespielt werden. Daraufhin ist der andere Spieler dran. 

### Ende des Spiels
Sobald ein Spieler mindestens 10000 Euro erlangt hat, hat dieser das Spiel gewonnen.

### Zusatz (Eventuell?)
Des Weiteren existiert pro Spieler ein zusätzlicher Stat, die Würfelanzahl. Am Anfang eines Zuges wird mit einem Würfelwurf entschieden wie viel Geld der Spieler zusätzlich in diesem Zug erhält. Die Anzahl an Würfeln kann erhöht/verringert werden mit Karten. Man kann bis zu 3 (4? 5?) Würfeln haben. 

# Arten von Karten
- Lehrerkarten

Grundbaustein eines Decks. Lehrerkarten haben folgende Attribute:

-	Allgemeine Informationen (Name, Beschreibung, Bild, etc.)
-	Fächer
-	Stats (z.B. Pünktlichkeit, Korrekturgeschwindigkeit, etc.)
-	Spezialfähigkeit
-	Eventuell passiv?

Die Spezialfähigkeit kann maximal einmal eingesetzt werden pro Spiel/Lehrer. Diese soll eine starke spielverändernde Fähigkeit sein. 

Sonst:
- Itemkarten
- Sabotagekarten
- Klassenraumkarten
- Aktionskarten
